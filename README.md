# Красильня

Покраска 3D-моделей: кисть, заливка областей, градиенты, наклейки с прозрачным фоном. Экспорт в GLB для Blender и Unreal.

Вся Красильня — это один файл `krasilnya.html`. Его можно открыть в браузере, а можно поставить как программу для Windows.

## Установка программы

1. Поставь [Node.js](https://nodejs.org) (версия LTS).
2. Скачай этот репозиторий: зелёная кнопка **Code → Download ZIP** или `git clone`.
3. В папке проекта открой терминал и выполни:

```
npm install
npm run build
```

4. Готовый установщик лежит в `dist\Krasilnya-Setup-1.0.0.exe`. Запусти его — появятся ярлыки «Красильня» на рабочем столе и в меню «Пуск».

Можно и без сборки: `npm start` запускает Красильню прямо из папки проекта.

Вместо шагов 3–4 можно дважды кликнуть `build.bat`.

## Как работают обновления

Программа при запуске заглядывает в этот репозиторий и сравнивает `krasilnya.html` со своей копией. Если файл изменился, она скачивает новую версию и предлагает перезапуститься. Без интернета открывается последняя скачанная версия.

Значит, чтобы выпустить обновление, достаточно запушить новый `krasilnya.html` в ветку `main`. Пересобирать `.exe` нужно только если меняются `main.js`, `preload.js`, `package.json` или иконка.

GitHub отдаёт свежий файл с задержкой до 5 минут. Проверить обновления вручную — **Ctrl+U**.

## Горячие клавиши программы

| Клавиша | Действие |
|---|---|
| Ctrl+U | проверить обновления |
| F5 / Ctrl+R | перезагрузить Красильню |
| F12 | инструменты разработчика |

Клавиши самой Красильни: B кисть, F заливка, G градиент, D наклейка, E ластик наклеек, S выделение, I пипетка, V камера, пробел — временно камера, [ и ] — размер кисти, Ctrl+Z / Ctrl+Shift+Z — отмена и повтор.

## Что где лежит

| Файл | Что это |
|---|---|
| `krasilnya.html` | сама Красильня: интерфейс и вся логика |
| `main.js` | окно программы, обновления, «Сохранить как», открытие файлов двойным кликом |
| `preload.js` | мостик между окном и программой |
| `config.json` | откуда брать обновления |
| `build/` | иконка |

three.js и JSZip программа берёт из своей папки, поэтому 3D работает без интернета.

## Если сборка падает

- **Ошибка про symbolic link / winCodeSign** — запусти терминал от имени администратора или включи «Режим разработчика» в параметрах Windows и повтори `npm run build`.
- **Windows SmartScreen ругается на установщик** — это потому, что программа не подписана. Нажми «Подробнее → Выполнить в любом случае».
